# Competition run sheet

Print this page and bring it to the tournament.

## Runs

| Run | Program | Hub slot | Start position | Attachment | Missions | Check before you press start |
|---|---|---|---|---|---|---|
| 1 | `competition/R1 Mission 7.llsp3` | 1 | _write it here_ | arm on motor D | 07 | arm in its start position |
| 2 | `competition/R2 Mission 11.llsp3` | 2 | _write it here_ | arm on motor D | 11 | arm in its start position, Mission 11 window up |

Fill in the start position the way you would tell a teammate. For example: "back on the black launch line, left side on the second tick".

## The night before

1. Charge the hub all the way.
2. Download each program to its slot. R1 goes in slot 1 and R2 in slot 2. The files already pick the right slot.
3. Leave slot 0 alone.
4. Run every slot once on a mat.
5. After that, don't change anything unless something is broken.

## At the table

- Start each run with the hub buttons, not the laptop. Bluetooth at a busy venue can drop.
- Pick the slot number on the hub, line up the robot, then press start.
- If a run goes wrong, write down what happened, then move on to the next run.

## Backups

Keep a copy of the `competition` folder in all of these places:

- on the hub,
- on the laptop,
- in Google Drive,
- on a USB stick.

## Changing a program

1. Make the change in a copy, not in the `competition` file.
2. Test it on the mat several times.
3. Only then replace the competition file. The old one goes in `archived-llsp3/` with the date in its name.
