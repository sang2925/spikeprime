      Run Controls

      The robot's whole body box counts, not just its centre. If any corner touches a wall (or a model ticked in BIOGLOW Missions), the run pauses. The body box is centred on the wheels until the body offset is measured.

      Closest approach (walls and ticked models, nearest first). Gap = robot body (and the front pusher, if ticked) to the outline, in mm. Clears on Reset or when you tick or untick a model.

      Turns (in-place spins this run). Turned = how far it spun. Centre moved = how far the point between the wheels slid: the simulator's wheels are perfect, so this stays 0 unless the two wheels were told different speeds. On the real robot, a turn that moves the centre means slipping or bumping into something. Nearest = the closest wall or ticked model during that spin, and which part of the robot was nearest.

      BIOGLOW Missions

      Rules copied from the Robot Game Rulebook and Challenge Updates (see README). The rulebook is the authority. This is not a scorer.

      Markers are labels placed from the wireframe, good to about 15 mm. They are not collision shapes.

      Models that stop the robot (all off to start with, all estimates). If the robot touches a ticked model, the run pauses, unless "push" is ticked.

      Outlines are read off the wireframe picture (good to about 5 mm). The real models' levers, plants and wires stick out further, and thin arms are left out. The robot touches Missions 06/07 and 11 on purpose, so ticking those will pause the run when it pushes them.

      Drive Settings

      Team robot = plain "move N cm" blocks drive 17.5-cm-per-wheel-turn too far (team record, 20.5 vs 17.5 cm) and every turn goes 5° too far (read from the gyro video). Both are estimates, not measurements. Ideal = the old simulator defaults. Changing either number by hand switches this to Custom.

      Wheel diameter is from the team record (about 20.5 cm per wheel turn). Everything else is an example or estimate, not a measurement of our robot.

      Encoder sign = which way the motor counts when its wheel rolls forward. It does not change which way the robot drives.
